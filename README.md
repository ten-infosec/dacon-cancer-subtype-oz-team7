## 팀 원칙
1. 공개 코드는 보지 않고 코드는 직접 작성 (과거 대회 코드 유사도 90% 이상이면 순위 제외)
2. `test.csv`는 예측할 때만 연다 — EDA·fit 모두 train만
3. 외부 데이터 금지. 논문의 유전자 목록 등 **지식**은 사용 가능 (`refs/`), 출처 기재
4. `SEED = 42` 고정, 최종 하이퍼파라미터는 숫자로 코드에
5. 실험마다 `logs/`에 기록 — 담당 · 가설 · CV 점수 · 리더보드 점수 · 해석 한 줄

## 폴더 구조
```
refs/          논문 보충자료에서 정리한 유전자 참조 목록 (환자 데이터 없음)
notebooks/     실험 노트북 — 파일명: {날짜}_{이름}_{실험}.ipynb
src/           공통 전처리 함수 (features.py)
logs/          Experiment Log (experiments.md) + 일일 기록
submissions/   리더보드 제출 파일 — 파일명: {날짜}_{실험ID}_cv{점수}.csv
docs/          발표 자료, 참고문헌
```
`data/`는 **커밋하지 않습니다** (.gitignore). 각자 로컬/드라이브에 두고 코드에서는 `DATA_DIR` 변수로 경로 지정.
